## Uso documental y RAG

Los archivos Markdown son la fuente textual controlada para indexación RAG. Los DOCX y PDF son copias de distribución del mismo contenido. La matriz XLSX estructura cada política en hojas aptas para importarse a Google Sheets.

Cada política identifica por separado:

- **Obligaciones legales verificadas:** síntesis de las fuentes oficiales citadas; no sustituye una revisión legal para un caso concreto.
- **Política interna ficticia:** decisiones operativas de NexoTico que pueden cambiar por versión y no se presentan como ley.

Las respuestas automatizadas deben citar el documento, versión y sección aplicable. Cuando una solicitud exija interpretar un contrato, incapacidad, sanción, dato sensible o caso no contemplado, el asistente debe escalarla a la Gerencia de Personas y Cultura y, si procede, a asesoría legal; no debe inferir una respuesta.
